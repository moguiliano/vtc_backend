# Campagne Google Ads

## Contexte

- **Budget** : 10 €/jour
- **Objectif** : appels + WhatsApp (06 74 03 96 94)
- **Zone** : Marseille 20 km + aéroport Marignane
- **Stratégie d'enchères** : Maximiser les conversions (100 conversions déjà enregistrées)
- **Tracking** : limité, les appels sont mesurés approximativement
- **Appareils** : mobile uniquement (100 % des conversions) → exclure tablettes et ordinateurs

## Mots-clés négatifs

- Concurrents apps : `uber`, `bolt`, `kapten`
- Hors offre (remboursement sécu) : `taxi conventionné`, `taxi médecin`, `VSL`
- Hors zone : `taxi allauch`, `taxi aubagne`
- Prix bas : `gratuit`, `pas cher`, `low cost`
